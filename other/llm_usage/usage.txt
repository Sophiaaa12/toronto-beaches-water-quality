Yes — a violin plot can be made from actual data, but there’s an important distinction between showing the actual observations and showing a summary/estimate derived from them.

For the STA2453/data-visualization idea of “show the actual data”:

Jitter plot / strip plot ✅ — each dot corresponds to an actual observation. This is the clearest example.
Scatter plot ✅ — each point is an actual observation.
Dot plot ✅ — individual observations are represented.
Rug plot ✅ — each tick corresponds to an observation.
Line plot ⚠️ — can show actual observations if each point is an observed value and the line merely connects them.
Histogram ⚠️ — based on actual data, but observations are aggregated into bins; you don't see each observation individually.
Boxplot ⚠️ — summarizes the actual data using median, quartiles, etc.; it does not directly display most individual observations.
Violin plot ⚠️ — also based on actual data, but the violin shape is a kernel density estimate, so the shape itself is not the raw/actual observations.

User:
what is rug plot?

ChatGPT:
A rug plot is a very simple way to show the actual individual data points along an axis.

Imagine your data are:

2, 3, 3.5, 6, 9
A rug plot looks roughly like:

|  | |     |        |
2  3 3.5   6        9
Each little vertical line | represents one actual observation. If lots of observations are close together, you'll see lots of little lines clustered there.

In ggplot2, you can add it using:

ggplot(df, aes(x = value)) +
  geom_density() +
  geom_rug()

Here, geom_density() gives you the estimated density curve, while geom_rug() shows where the actual observations are.

So conceptually:

Density/violin → estimated shape of distribution
Rug → actual observations

That's why rug plots are useful when your reading says graphs should convey as much of the actual data as possible.
